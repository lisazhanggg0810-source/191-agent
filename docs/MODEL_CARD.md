# CRC-LNM 比赛部署模型卡

## 用途

用于结直肠癌淋巴结转移风险研究中的流程演示、病例复核和工程验证。输出需要影像科、病理科、胃肠外科或肿瘤 MDT 专业人员结合完整资料复核。

## 冻结输入

- CT 影像组学：1409 维，shape 14、original 93、wavelet 744、transformed 558。
- 病理：患者级 768 维预提取向量。
- 临床：`age`、`male`、`Type`、`T`。
- 特征名称、顺序、类别词表和标准化参数必须与部署包一致。

## 模型信息

- 架构：`attention_path_ct_clinical`。
- 集成成员：5。
- 训练队列：`all_460`。
- 部署阈值：`0.3529504342004657`。
- Schema：`1.0.0`。
- 特征顺序哈希：`d4a5ecb56733db87f505473a7be1497a7fdd174c0994748d5b9574f7373d3200`。
- 模型版本/manifest SHA-256：`003636d691d603908f8bd913b5ab7769a5e1479680c7f8317cda1d106e8bf73f`。

## 性能声明

开发阶段 OOF ROC-AUC 为 `0.7749`，仅用于说明开发过程，不等于当前部署权重的独立测试性能。比赛部署包由全部 460 例重新训练，固定返回 `independent_test_claim=false`。

合成黄金病例 `demo_case_001` 的概率 `0.6279473900794983` 只用于代码、模型文件和容器回归，不代表临床准确率、敏感性或特异性。

## 已知限制

- 没有在本发布包中提供独立外部验证证据。
- 输入依赖既有预提取特征，不能接收其他特征工程产生的同维向量。
- 不处理原始 CT、ROI 或 WSI。
- 不生成病理热图或因果解释。
- 队列来源、设备、扫描协议、人群和类别分布变化可能降低泛化能力。
- 模型概率不能单独作为诊断、分期、治疗或预后依据。

## 安全和隐私

病例包必须完全脱敏，只使用研究 ID。服务验证 manifest、文件大小、SHA-256、精确键集、有限数值以及 PII/标签泄漏字段。高维输入保留在短期服务端 artifact 中，不返回 Nexent 上下文。
